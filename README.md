# LOGazer

## En
Long story short, this tool performs a fairly simple task. It analyses the `Last Oasis` game screen and takes a screenshot if it spots something valuable to share with other gamers later.
At the moment, it is tuned only for 2560x1440 screen dimesions.
Other dimensions will be added later if need.

All screenshots are placed in the `./screenshots` folder. Do not forget to clean this folder sometimes because it can take a LOT of space!

## Ru
Эта штука смотрит вместе с вами на ваш игровой экран (Last Oasis) и делает скриншот когда видит что-то хорошее.
На текущий момент она настроена на экран 2560x1440, в других разрешениях не тестировано. если надо будет - добавлю ещё и другие.
Все скриншоты лежат в каталоге ./screenshots и их там набирается прорва, так что этот каталог желательно чисить, если только у вас не безразмерный диск. =)
